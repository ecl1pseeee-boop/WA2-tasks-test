# Требования


| # | Требование | Число | Откуда | Чем проверяется | Статус |
|---|---|---|---|---|-|
| 1 | все восемь функций работают (регистрация, вход паролем, вход через GitHub, подача объявления, поиск, просмотр объявления, комментарий, открытие страниц) | 8 из 8 | письмо заказчика (документ 4) | `./smoke.sh` | ✅ |
| 2 | страница отвечает не дольше | ≤ 3 с | «чтобы не крутилось вечно» — порог предложен нами по письму заказчика | замер `curl -s -o /dev/null -w '%{time_total}'`, три прогона | ✅ |
| 3 | вся система помещается в выданный сервер | ≤ 3 из 4 ГБ памяти, ≤ 60 из 80 ГБ диска | VPS 2 ядра / 4 ГБ / 80 ГБ, бюджет 10 тыс. в письме заказчика | `docker stats --no-stream`, `df -h` | ✅ |
| 4 | развернуть с нуля на чистой машине | ≤ 30 мин, обращений к автору — 0 | «что будет, если вы пропадёте» — письмо заказчика | учение 1 (чистый клон + README) | ✅ |
| 5 | найти по карте место, где обрабатывается конкретный сценарий | ≤ 5 мин, без подсказок | там же | проверка на человеке, не писавшем код | ? |
| 6 | подняться после перезагрузки хоста | ≤ 10 мин, одна команда (`docker compose up -d`) | «поднималось без шаманства» — письмо заказчика | учение 2 (`sudo reboot` → `docker compose up -d && ./smoke.sh`) | ✅  |
| 7 | секретов (паролей, ключей) в репозитории | 0 | *дописано нами*: репозиторий передаётся заказчику и, возможно, другим людям | поиск по коду | ❌ — найден пароль от MySQL в коде, см. `TECH_DEBT.md` №1 (`services/api/app/main.py:18`) |
| 8 | сборка воспроизводима: образы с конкретными тегами, зависимости зафиксированы | версии зафиксированы, без `latest` | *дописано нами*: без этого «разверните сами» — лотерея | проверка тегов образов в `docker-compose.yml`/`Dockerfile`, наличие `composer.lock` и `requirements.txt` | ✅ |

## Как читать статус

- ✅ — проверено в текущем состоянии репозитория, требование выполняется.
- ❌ — проверено, требование не выполняется; ссылка на дефект в `TECH_DEBT.md`.
- ? — ещё не измерено/не прогонялось в рамках этой сессии работы над практикой; требует замера или учения (блоки C, D, F методички) до сдачи отчёта.
